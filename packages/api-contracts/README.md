# API contracts

Generated Nest OpenAPI models and Fetch operations shared by web and future edge runtimes.

Start Nest, then run from this package:

```bash
pnpm gen:api
pnpm gen:api:check
```

`NEST_OPENAPI_URL` defaults to `http://localhost:5040/api/docs-json`. Generated files live in `src/generated/`; do not edit them by hand.
